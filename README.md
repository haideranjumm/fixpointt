# FixPoint website

Static one-page site (German + English). Deploy on Vercel:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/haideranjumm/fixpoint)

Replace YOUR-GITHUB-USER/YOUR-REPO with your repository URL. The button works once the repo is public.
Framework preset: "Other". No build command. Output directory: leave empty.
